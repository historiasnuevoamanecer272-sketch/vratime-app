# VratiMe — система пиктограмм

## Источник

Рабочая библиотека пиктограмм находится в `src/components/Icon.jsx`. Новая пиктограмма сначала добавляется туда, затем фиксируется в этом документе. Эмодзи и случайные сторонние наборы в рабочем интерфейсе не используются.

## Общие правила

- Контур 2 px, скруглённые окончания и соединения.
- Базовая сетка `24 × 24`.
- Иконка сопровождает текст у важных действий; одна иконка без подписи допустима только при однозначном `aria-label`.
- Цвет не является единственным носителем смысла.
- В одной сущности не смешиваются пиктограммы разных стилей.
- Растровая предметная иллюстрация не заменяет пиктограмму действия.

## Семантическая карта

| Смысл | Имя в `Icon.jsx` | Где использовать |
| --- | --- | --- |
| Карта | `map` | нижняя навигация, географический обзор |
| Сделки | `deals` | нижняя навигация, статистика |
| Создать | `plus` | центральное действие |
| Профиль | `user` | навигация и данные пользователя |
| Отдаю | `gift` | тип объявления и действие владельца |
| Ищу | `search` | тип объявления «Ищут», поиск |
| Готов передать | `handover` | предложение вещи по объявлению «Ищут» |
| Запрос и контакт | `message` | первый этап сделки |
| Бронь | `clock` | срок и второй этап сделки |
| Передача завершена | `handshake` | третий этап сделки |
| Активные | `activity` | активные договорённости |
| История | `history` | завершённые и отменённые сделки |
| Дата | `calendar` | дата объявления или сделки |
| Количество | `box` | число единиц |
| Адрес | `location` | место передачи |
| Подтверждено | `check` | успешное действие и завершённый этап |
| Отменено/закрыть | `close` | отмена или закрытие |
| Рейтинг | `star` | оценка и рейтинг |
| Закрытый уровень | `lock` | ещё не достигнутая медаль в каталоге уровней |
| Экология | `leaf` | экобаллы и вклад |
| Черногория/регион | `mountain` | декоративные заголовки, не рабочие кнопки |
| Адриатика | `waves` | декоративные заголовки и региональный контекст |

## Цветовые роли

- «Отдают» и завершённые действия — `--reuse`.
- «Ищут» и поиск — `--adriatic`.
- Ожидание решения — `--sand`.
- Активная бронь — `--terracotta`.
- Отмена — `--danger` или нейтральный каменный фон в истории.
- Общие основные действия — `--forest`.

## Запрещённые подмены

- Грузовик не обозначает поиск вещи или готовность передать её.
- Лупа не обозначает физическую передачу.
- Подарок не используется для объявления «Ищу».
- Логотип VratiMe не повторяется вместо обычной пиктограммы.
- Категорийные WebP-иллюстрации не используются в чипах, маркерах карты и нижней навигации.

## Проверка

Перед релизом проверить пиктограммы на размерах 16, 20, 24 и 32 px, в светлом и цветном контейнере, при RU/ME/EN подписях и с клавиатурным фокусом.
