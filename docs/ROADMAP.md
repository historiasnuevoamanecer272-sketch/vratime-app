# Roadmap VratiMe

## P0 — надёжность и завершение действующих функций

- Завершить тестовое подключение Tribute и проверить идемпотентность webhook.
- Провести живой E2E сделки двумя изолированными тестовыми аккаунтами.
- Добавить автоматическую проверку актуального production asset hash после деплоя.
- Проверить истечение 24-часовой брони на контролируемых тестовых данных.

## P1 — качество обмена

- Уведомлять владельца о новом запросе без раскрытия данных посторонним.
- Добавить понятный счётчик ожидающих запросов у владельца объявления.
- Сделать причину отмены понятной обоим участникам.
- Добавить мягкое напоминание перед истечением брони.
- Улучшить обработку объявлений без фотографии и поощрять добавление фото.

## P1 — визуальная система

- Последовательно применить региональные поверхности и смысловые цвета ко всем экранам.
- Дополнять пиктограммы только через `Icon.jsx` и `design/ICONOGRAPHY.md`.
- Создать дополнительные региональные иллюстрации для пустых состояний и успеха без дублирования пользовательских фотографий.
- Проверять каждый визуальный релиз на RU/ME/EN и пяти обязательных размерах.

## P2 — сообщество и модерация

- Интерфейс ручной проверки risk flags без автоматического наказания.
- Жалоба на объявление и безопасная очередь модерации.
- Добровольные локальные подборки и инициативы повторного использования.
- Метрики повторного использования без публикации персональных данных.

## Не планируется без отдельного решения

- Платные объявления или комиссия со сделки.
- Продажа пользовательских данных.
- Автоматический бан по одному risk flag.
- Игровое преимущество за донаты.
