# VratiMe — правила генерации визуалов

Этот документ обязателен для новых растровых иллюстраций VratiMe: категорий, пустых состояний, успехов, достижений и небольших объясняющих визуалов.

## Роль визуала

VratiMe — тёплый сервис повторного использования вещей в Черногории. Визуал должен передавать **круговорот, практическую пользу, лёгкость и доверие**. Он не должен выглядеть как армейский интерфейс, складская система, детская игра или обычный «зелёный» эко‑клипарт.

Основной знак — лист внутри стрелки-круговорота. Использовать его как идею, но не рисовать рядом с каждой иллюстрацией буквально.

## Неподвижные правила стиля

- Фон: настоящий прозрачный, без белой или цветной плашки.
- Манера: refined editorial semi-flat 3D / paper-cut illustration; мягкие объёмы, чистые края, ненавязчивые тени.
- Настроение: спокойный средиземноморский день, чистый воздух, человечность без персонажей крупным планом.
- Палитра: морская бирюза `#0B8FA5`, тёмная бирюза `#075D63`, свежий зелёный `#78B97A`, светлая аква, натуральный крафт/дерево только как акцент материала.
- Композиция: один главный предмет или компактная группа из 2–4 предметов, центр кадра, широкие прозрачные поля по краям.
- Детали: материал должен быть узнаваем в размере 56–96 px. Лучше меньше объектов, чем мелкая «каша».
- Текст: никогда не генерировать. Все подписи живут в интерфейсе и переводятся через i18n.

## Что нельзя

- Тёмный фон, рамка, карточка, готовый макет приложения.
- Логотипы, названия брендов, буквы, цифры, водяные знаки.
- Фотореалистичные лица, узнаваемые люди, одежда с брендами.
- Неон, кислотные зелёные цвета, тяжёлое золото, «гербовые» медали.
- Резкая мультяшность, стоковый клипарт, плоские иконки поверх объёмной сцены.
- Случайная коричнево‑оливковая доминанта: крафт и дерево допустимы только как реальные материалы.

## Где какой тип изображения применять

| Место | Допустимый визуал | Размер в UI |
| --- | --- | --- |
| Карточка основной категории | Иллюстрация семейства материалов | 80–96 px |
| Подкатегория без пользовательского фото | Нативная контурная иконка | 24–42 px |
| Объявление с фото | Только пользовательское фото | карточка/карта |
| Пустой список | Оптимистичный предметный сюжет | 84–112 px |
| Завершённая сделка/оценка | Передача предмета без лиц | 96–118 px |
| Награда | Нативная иконка в единой плитке | 42 px |

Не использовать предметные иллюстрации в мелких чипах, маркерах карты или нижней навигации: там остаются нативные line‑icons.

## Шаблон промпта

```text
Use case: stylized-concept
Asset type: <where the asset appears in the VratiMe PWA>
Primary request: <one concrete material or event>
Scene/backdrop: genuine transparent background, no tile, no card, no frame.
Style/medium: refined editorial semi-flat 3D paper-cut illustration;
soft rounded forms, fine contours, recognisable at small size.
Color palette: sea teal #0B8FA5, forest teal #075D63,
fresh green #78B97A, pale aqua highlights, restrained natural kraft/wood accent if appropriate.
Lighting/mood: calm Mediterranean daylight, clean, optimistic, trustworthy.
Composition/framing: centered compact still life with generous transparent margins.
Constraints: no text, no letters, no logos, no watermark, no dark background,
no UI mockup, no clip-art, no photorealistic people.
```

Для передачи между людьми добавить: `two anonymous hands` и `no faces, no identifying details`.

## Текущие эталоны

Эталонные файлы находятся в `src/assets/visuals/v1/`:

- `category-glass-v1.webp`
- `category-textile-v1.webp`
- `category-paper-v1.webp`
- `category-packaging-v1.webp`
- `category-pallet-v1.webp`
- `empty-listings-v1.webp`
- `deal-complete-v1.webp`

Новый визуал сначала сохраняется новой версией (`*-v2.webp`), не заменяя эталон. После приёмки его оптимизируют до WebP, максимум 384 px по длинной стороне, и проверяют на прозрачность, читаемость на мобильном экране и отсутствие текста.

## Контроль перед добавлением

1. Узнаётся ли предмет в 56 px?
2. Есть ли прозрачный фон и нет ли текста?
3. Поддерживает ли палитра бирюзово‑зелёную систему?
4. Не конкурирует ли иллюстрация с пользовательской фотографией?
5. Весит ли итоговый WebP разумно: ориентир 15–30 КБ, максимум 50 КБ?
6. Проверены ли мобильный и desktop размеры, а также `prefers-reduced-motion`?
