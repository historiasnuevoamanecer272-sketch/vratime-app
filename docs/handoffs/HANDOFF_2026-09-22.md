# Handoff — 22 сентября 2026

## Статус

Ветка `codex/vratime-16-point-plan` содержит подготовленную реализацию утверждённого плана из 16 пунктов. Локальные проверки проходят, но production всё ещё находится на release `vratime-20260921-auto-verify-8fc8f72`: миграция и deploy намеренно не выполнены без входа владельца в Supabase и отдельного подтверждения изменения RLS.

## Что реализовано в коде

- роли, модерация объявлений, жалобы, санкции, обращения и аватары;
- обязательный подтверждённый адрес, редактор объявлений и запрет публикации/брони без него;
- поиск только по «Отдают» при текстовом запросе, пять уровней, годовой расчёт 2026;
- профиль с отдельными секциями, таймеры 48/24 часа, крупные постоянные подтверждения;
- цветная навигация и короткие анимации, учитывающие `prefers-reduced-motion`;
- расширенный live-E2E сценарий пяти пользователей и команда безопасного назначения первого администратора.

## Следующий безопасный порядок

1. Войти в Supabase SQL Editor проекта `kuoflaaankpjksyssfka`.
2. После явного подтверждения владельца применить `supabase/migrations/20260922000000_roles_moderation_reports_support.sql`.
3. Запустить `npm run db:e2e`, затем `npm run test`.
4. Собрать и задеплоить immutable release, проверить `npm run test:production` и интерфейс на desktop/mobile.
5. Обновить `CURRENT_STATE.md` точными release ID и commit, создать итоговый архив с SHA-256.

- Не изменять существующие пользовательские архивы или удалённый пользователем логотип.
