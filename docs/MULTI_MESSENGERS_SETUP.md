# Несколько мессенджеров

Миграция `20260820233000_multi_messenger_contacts.sql` переводит `profile_contacts` с одного контакта на несколько: Viber, WhatsApp и Telegram одновременно.

- Уже сохранённый контакт остаётся на месте и становится первым каналом пользователя.
- Контакты остаются закрытыми от посторонних: они доступны только владельцу профиля и участникам конкретной сделки через `get_my_deals`.
- У каждого канала может быть свой номер телефона.
- Telegram можно сохранить как публичный `@username` или как номер в международном формате, например `+38267123456`.
- Для Telegram по номеру приложение создаёт ссылку `https://t.me/+номер`; она сработает, если настройки приватности Telegram разрешают поиск этого пользователя по номеру.

Чтобы включить функцию, примените все миграции из корня проекта:

```powershell
npm run db:migrate
```

Команда использует переменные `SUPABASE_DB_HOST`, `SUPABASE_DB_PORT`, `SUPABASE_DB_NAME`, `SUPABASE_DB_USER` и `SUPABASE_DB_PASSWORD`. После применения проверьте транзакционные правила:

```powershell
npm run db:check
npm run db:test
npm run db:e2e
```

До миграции приложение оставляет рабочим выбор одного канала, но не позволит незаметно потерять дополнительные выбранные контакты.
