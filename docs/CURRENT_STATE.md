## Релиз-кандидат 23 сентября (ожидает переключения статического сайта)

В ветке `codex/vratime-16-point-plan` собран и проверен следующий релиз. Его схема уже применена к production Supabase, но интерфейс **не считается опубликованным**, пока сервер не начнёт отдавать новую сборку.

- Роли `user`, `moderator`, `admin`, защищённое первое назначение администратора и панель очередей персонала.
- Модерация новых и существенно отредактированных объявлений; в публичную карту попадают только одобренные объявления с подтверждённым адресом.
- Обязательный выбранный адрес/координаты, редактирование собственных объявлений, аватары, жалобы и обращения в поддержку.
- Разделение профиля на собственные объявления, ответы, бронирования и историю; 48-часовой срок запроса и 24-часовой срок принятой брони.
- Поиск по тексту только среди «Отдают», пять уровней `0 / 50 / 225 / 500 / 950`, цветная навигация и доступные короткие анимации.
- Годовое финансирование, считающее остаток до 31 декабря ежедневно, отдельно от фактически собранных средств.
- Избранное, сохранённые поиски и максимум один персональный дайджест в день; общая история поиска не публикуется.
- Общественные пункты сбора с подтверждением несколькими разными участниками, материалами и мягкими правками без автопубликации чужих данных.
- Частичный резерв количества, запись встреч, отметки неявки, временная передача/возврат и агрегированное влияние повторного использования.

Свежие проверки 23 сентября: `npm test`, `npm run db:public` и `npm run db:e2e` прошли. Последняя команда очистила созданные тестовые строки и пользователей. `npm run test:production` намеренно остаётся красной только потому, что домен возвращает старые assets; её нужно повторить сразу после deploy.

## Логика объявления

- Обычный запрос не скрывает объявление с карты.
- Для отправившего запрос объявление приглушено и помечено «Запрос подан».
- После принятия одного запроса объявление получает статус `reserved` и исчезает с карты.
- Остальные открытые запросы закрываются с причиной `another_request_accepted`.
- Через 24 часа неподтверждённая бронь истекает; объявление снова становится активным.
- Завершение требует подтверждения обеих сторон.

## База и приватность

- Контакты выдаются через SECURITY DEFINER RPC только участникам их сделки.
- Анонимный доступ к приватным RPC отозван.
- Тип `listings.type` явно приводится к `text` в контракте `get_my_deals`.
- Миграционная топология и security-инварианты проверяются `npm run test:migrations`.
